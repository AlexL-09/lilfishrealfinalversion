# PixelPurl

`PixelPurl.ttf` is the original, unmodified font supplied by the user from `/Users/smitpatil/Downloads/PixelPurl.ttf`.

The font identifies itself as PixelPurl Medium and includes the copyright name IgorOvsyannykov. No separate license accompanied the supplied file; no license classification is asserted here.

The renderer uses explicit raster DPI 1, nearest filtering, and eight-pixel size increments. Captions start at 24 pixels, controls at 32. Body text has no shadow; headings and button labels use a one-pixel shadow.
