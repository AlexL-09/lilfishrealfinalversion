# lilfishrealfinalversion
lil fish vs big bosses (go fish)
A LÖVE card game about a tiny fish learning Go Fish with an axolotl trainer and facing a pelican, a shark, and a colossal squid in an underwater television studio.
<br></br>
Music asset: Music: "Fragment of Tomorrow -アスノカケラ-" by Space_Cat, via Pixabay

Run: <br></br>
Download the repository ZIP and extract it, then follow the instructions for your platform
